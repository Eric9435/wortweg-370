# WortWeg 370 — German Lifetime Vocabulary

German–English–Myanmar multiple-choice vocabulary practice with German pronunciation, spaced repetition, wrong-answer review, and locally saved progress.

## Features
- 370-topic roadmap and 10,876 A1–C2 vocabulary entries
- Topic 1 has 41 curated personal-identity entries
- Other topic-specific word sets are not yet curated; use the A1–C2 bank for those words
- German text-to-speech (requires compatible browser voice)
- Historical Round 5: 4/10 with six incorrect words preloaded
- Progress stored locally, with JSON export/import; no cloud sync

## Install on iPhone
After GitHub Pages is enabled, open the website in Safari and choose Share → Add to Home Screen.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
