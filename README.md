# WortWeg 370

### Learn German from A1 to C2 — with German, English and Myanmar

**WortWeg 370** is an independently developed, multilingual German-learning platform that brings vocabulary, grammar, reading, dialogue practice, verb forms and interactive sentence construction into one web application. It is designed for structured self-study, with mobile-first lessons, offline support and progress tracking.

### Lifetime Sentence Builder: 360 exercises

Sentence Builder is a standalone learning workspace, connected from the main menu.

- **12 English tense/aspect comparisons** (present, past and future forms) × **10** exercises = **120** sentence puzzles.
- **24 additional German grammar topics**, four each at **A1, A2, B1, B2, C1 and C2**, × **10** exercises = **240** sentence puzzles.
- **36 total topics / 360 exercises**, with `All`, `Tenses` and A1–C2 filters.
- Touch-friendly **drag-and-drop** and **tap-to-place** word cards, without mandatory typing.
- A **V1/V2/V3 verb bank** for the exercise, a short Myanmar grammar explanation, grammar-pattern hints, undo, reset and answer checking.
- Per-topic mastered counts, resume navigation and progress saved in local browser/device storage.
- Existing mastery records from the original 120-exercise tense section are retained.

**Practice limitation:** The checker currently compares the arranged words with an authored reference sentence. Another grammatical German word order may also be valid but can be marked as different; it is **not yet a full grammatical parser or free-writing evaluator**. Word cards already contain the required inflected forms, so constructing the sentence does not by itself verify the ability to produce every conjugation or case ending independently. A revealed answer does not award mastery.

**Coverage limitation:** The 24 A1–C2 grammar topics in Sentence Builder are **not** 10 individually authored exercises for each of the 288 Lifetime Grammar reference topics. Content expansion and professional linguistic review remain ongoing.

### Vocabulary, articles and flashcards

- Search and browse the full embedded A1–C2 bank; paginate by 100/250/500 entries or use continuous scrolling.
- Study through quizzes, pronunciation playback, wrong-answer lists and review tools.
- Flip German–English/Myanmar flashcards and rate them **Again** or **I knew it**.
- Explore noun gender (der/die/das), noun expansion, and **347 Special Vocabulary** records across connectors, prepositions, interjections, directions, numbers and time.
- See studied vocabulary in **My Seen Words**, including flashcard and quiz review history.
- The **370-topic roadmap** provides navigation and practice; it does **not** imply 370 separately polished, complete textbooks. Topic-specific curation remains uneven.

### Grammar and memorization

**Grammar Academy** offers 200 A1–C1 topic records (40 per level) with a learning rule, German examples, English/Myanmar support and interactive checks. These are short first-pass lessons; depth varies by topic.

**Lifetime Grammar** is a separate A1–C2 reference collection with 36 chapters and **288 stable topic IDs** (`T001`–`T288`), focused rules, examples and bilingual English/Myanmar guidance. It includes **48 reviewed priority paradigms** and a separate **Memorize 48** chart library with hide/reveal cells and study tracking. Other entries are focused reference material, not all exhaustive declension tables or automatically graded lessons.

### Reading, dialogues and Goethe preparation

**Reading** provides level-based passages and reading tools across A1–C2, including German narration where supported.

**Dialog Studio** is independent of the vocabulary and grammar menus. It contains authored situations across all six levels, including A1 everyday conversations, B-level extended dialogues and C-level academic/professional discourse. Learners can view German/English turns, play speech at different speeds, mask responses for role-play and access Myanmar word meanings. Source-linked word drills reference records from multiple vocabulary collections; their totals should not be treated as unique CEFR words.

**Goethe Exam Preparation** includes topic guidance, listening/reading/writing/speaking practice, sample questions, checklists, and links to **official Goethe practice materials**. WortWeg's internally authored tasks are **not official Goethe exam questions**. The module is a preparation aid, not an accredited assessment or guaranteed exam-readiness score.

## Platforms and technical design

| Platform | Availability and limitations |
| --- | --- |
| **Web / PWA** | [Live on GitHub Pages](https://eric9435.github.io/wortweg-370/); responsive UI with cached offline-capable assets |
| **Android** | Installable **development-preview APKs** under [Releases](https://github.com/Eric9435/wortweg-370/releases). A published APK may lag behind the latest website code. |
| **iOS** | Capacitor/Xcode project source is present; public signed iOS distribution and production authentication configuration are not established here. |

**Core stack:** HTML, CSS and JavaScript; Firebase Authentication and Firestore for supported account data; service worker and web app manifest for PWA behaviour; Capacitor and native Android/iOS projects for mobile packaging; GitHub Actions for CI and release builds.

The UI includes light/dark themes, responsive navigation, pronunciation tools and on-device study tracking. Google sign-in/cloud sync requires network access. **Not every module shares the same sync implementation:** for example, Sentence Builder progress is device-local and should be backed up before clearing site data, reinstalling an app or switching devices. Offline functionality also varies by resource; resources not previously cached cannot always be fetched offline.

### Dynamic lesson updates

A versioned JSON feed at [`content/v1/pack.json`](content/v1/pack.json) supports compatible **new lesson and vocabulary content** updates without reinstalling the native preview:

1. Add or update content records while keeping stable lowercase, hyphenated IDs.
2. Increase the pack's numeric `version` and update `updatedAt`.
3. Commit the update to `main` and publish the website.
4. The compatible app can fetch the new text-only content when online and reuse its cached copy offline.

**Important:** This feed does **not** automatically replace the original 10,876-entry embedded word bank, upgrade JavaScript features, update native permissions or install a new APK. UI/native-code changes require a fresh build. See [`live-content.js`](live-content.js) for the feed consumer.

## Run locally

The web project is static and can be served without a framework build:

```bash
git clone https://github.com/Eric9435/wortweg-370.git
cd wortweg-370
python3 -m http.server 5500
```

Open [http://localhost:5500](http://localhost:5500). Use the published HTTPS origin when testing deployed Google sign-in, or configure the appropriate authorized domains in Firebase for another development origin.

### Mobile development

Use Node.js 22, npm and the platform toolchains. From the repository root:

```bash
cd mobile
npm ci
npm run test:account
npm run sync
npm run icons
```

Build Android using the Android SDK/Gradle project or iOS using Xcode and Apple signing. See [mobile/README.md](mobile/README.md) and [mobile release notes](mobile/RELEASE-NOTES.md).

**Android Google login:** Firebase Android OAuth must register the SHA-1 fingerprint of the **actual signed APK** for package `com.innovatex.wortweg370.preview`. Do not reuse the fingerprint of an unrelated keystore. Release assets, signing information and configuration should be checked for the specific build.

## Known limitations and roadmap

1. **Pedagogical validation:** Conduct systematic native-German review of grammar explanations, translations, tense equivalences, verb variants and CEFR placement; broaden authored practice depth.
2. **Answer checking:** Accept valid alternative word order and add richer mistake-specific explanations, inflection choices, conjugation drills and optional free writing.
3. **Skills assessment:** Expand interactive listening, pronunciation, speaking and writing evaluation beyond reference audio and self-guided prompts.
4. **Progress sync:** Unify cloud-backed progress and recovery across all modules, including Sentence Builder and locally saved study collections.
5. **Production readiness:** Improve accessibility, test across actual Android/iOS devices, validate offline edge cases, strengthen analytics and prepare signed public mobile releases.

A feature list alone should not be interpreted as a 10/10 product-quality audit or proof of Goethe/CEFR mastery.
